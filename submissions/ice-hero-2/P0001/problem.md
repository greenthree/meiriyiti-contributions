# 冰之勇者记2

### 题面描述

冰之勇者才不是笨蛋！她很快就发现，世界并不是只有两格宽，而是一个 $n \times n$ 的大网格。

勇者从左上角 $(1,1)$ 出发，公主被关在右下角 $(n,n)$。网格中 `0` 表示可以通行的道路，`1` 表示无法通过的障碍。勇者每次可以向上、下、左、右移动一格，不能走出网格，也不能走进障碍。

不管公主离得多远，勇者都想用最少的步数找到她。请你算出从 $(1,1)$ 到 $(n,n)$ 的最短步数。

### 输入描述

第一行一个整数 $n$（$1 \le n \le 1000$）。

接下来 $n$ 行，每行一个长度为 $n$ 的字符串，仅由字符 `0` 和 `1` 组成，表示网格从上到下的每一行。

保证 $(1,1)$ 与 $(n,n)$ 所在位置均为 `0`，并且至少存在一条从 $(1,1)$ 到 $(n,n)$ 的合法路径。

### 输出描述

输出一行一个整数，表示从 $(1,1)$ 到 $(n,n)$ 的最短步数。

### 样例

**【样例 1】**

**样例输入：**

~~~text
1
0
~~~

**样例输出：**

~~~text
0
~~~

#### 样例解释 #1：

起点和终点是同一个格子，勇者不需要移动，步数为 $0$。

**【样例 2】**

**样例输入：**

~~~text
3
000
010
000
~~~

**样例输出：**

~~~text
4
~~~

#### 样例解释 #2：

勇者可以沿第一行走到 $(1,3)$，再向下经过 $(2,3)$ 到达 $(3,3)$，共走 $4$ 步；也可以先向下再向右，最短步数同样是 $4$。

**【样例 3】**

**样例输入：**

~~~text
5
00000
11110
00000
01111
00000
~~~

**样例输出：**

~~~text
16
~~~

#### 样例解释 #3：

第二行只有第 $5$ 列可以通行，第四行只有第 $1$ 列可以通行。勇者必须先向右走到 $(1,5)$，向下进入第三行，再向左走到 $(3,1)$，向下穿过第四行，最后向右走到 $(5,5)$，一共 $16$ 步。这条路线出现了向左移动，说明只允许向右、向下走的贪心是不对的。

### 提示

- $1 \le n \le 1000$，时间限制 $1$ 秒，空间限制 $256$ MB。
- 勇者可以向四个方向移动，不只能向右或向下走。
- 起点 $(1,1)$ 和终点 $(n,n)$ 保证是 `0`，且保证至少有一条合法路径。
- 输出末尾有没有换行都算正确。
