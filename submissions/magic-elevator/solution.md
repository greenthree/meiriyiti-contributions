# 魔法电梯 题解

## 1. 题意简述

一栋大楼共有 $n$ 层（编号 $1 \sim n$）。电梯当前在第 $s$ 层，目标是到达第 $t$ 层。
电梯有三个按钮：
1. 向上移动 $a$ 层（到达 $x + a$，要求 $\le n$）；
2. 向下移动 $b$ 层（到达 $x - b$，要求 $\ge 1$）；
3. 翻倍传送到 $2x$ 层（要求 $\le n$）。

求从小 G 所在的第 $s$ 层到达第 $t$ 层所需的最少按键次数；若无法到达则输出 `-1`。

## 2. 解题思路

本题要求从起点 $s$ 到达终点 $t$ 的“最少按键次数”。在图论中，我们可以把每个楼层看作一个节点，按下按钮看作一次边权为 $1$ 的状态转移：
- 节点 $x$ 可以连向 $x + a$（若 $x + a \le n$）；
- 节点 $x$ 可以连向 $x - b$（若 $x - b \ge 1$）；
- 节点 $x$ 可以连向 $2x$（若 $2x \le n$）。

因为所有转移的代价都为 $1$（即按一次按钮），求最少步数的问题就是典型的**无权图单源最短路问题**。解决这一问题的标准算法是**广度优先搜索（BFS）**。

### 广搜流程：
1. **状态表示**：定义一个距离数组 `dist`，其中 `dist[i]` 表示从起点 $s$ 到达第 $i$ 层的最少按键次数。初始化所有位置为 `-1`，表示尚未到达；
2. **起点入队**：起点 $s$ 的步数为 $0$（即 `dist[s] = 0`），将 $s$ 加入队列；
3. **特判起点即终点**：如果 $s = t$，不需要按任何按钮，直接输出 $0$；
4. **层层扩展**：
   - 当队列不为空时，取出队首楼层 $u$；
   - 尝试三种可能的移动：
     - 若 $u + a \le n$ 且尚未访问过（`dist[u + a] == -1`），则更新 `dist[u + a] = dist[u] + 1` 并将 $u + a$ 入队；
     - 若 $u - b \ge 1$ 且尚未访问过（`dist[u - b] == -1`），则更新 `dist[u - b] = dist[u] + 1` 并将 $u - b$ 入队；
     - 若 $2u \le n$ 且尚未访问过（`dist[2 * u] == -1`），则更新 `dist[2 * u] = dist[u] + 1` 并将 $2u$ 入队；
   - 若某次转移直接到达了终点 $t$，即可立即输出对应的距离；
5. **无法到达**：若队列已空仍未能到达第 $t$ 层，则说明终点不可达，输出 `-1`。

### 复杂度分析：
- 大楼总层数为 $n$（$n \le 10^5$），每个楼层作为状态至多入队一次；
- 每个状态向外扩展至多 $3$ 个新状态；
- 因此时间复杂度为 $O(n)$，空间复杂度为 $O(n)$，可在 $1$ 秒的时限内轻松通过。

## 3. 常见易错点

1. **起点与终点相同**：若 $s = t$，最少步数为 $0$。如果不加特判，可能会误走一步导致输出错误；
2. **楼层范围越界**：
   - 向上移动或翻倍时必须保证不超过总层数 $n$；
   - 向下移动时必须保证不低于最低层数 $1$；
   - 在 C++ 中判断翻倍 $2u \le n$ 时，若楼层数值极大需留意整型溢出（本题中 $2 \times 10^5$ 在 32 位整型内，但养成防溢出习惯更好）；
3. **漏写访问标记 / 重复入队**：如果没有使用 `dist` 数组或 `vis` 数组记录访问状态，可能会导致电梯在两个楼层之间反复震荡（如 $+a$ 后 $-b$ 循环），从而陷入死循环（TLE）；
4. **贪心盲目决策**：不能贪心地每次都选离终点最近的按钮，局部贪心容易错过先向相反方向移动再翻倍到达终点的全局最优解；
5. 所有题目均不强求在最后一行输出后换行。

## 4. 参考代码与语法精讲

### 4.1 C++ 参考代码

```cpp
#include <bits/stdc++.h>

using namespace std;

int main()
{
    int n, s, t, a, b;
    cin >> n >> s >> t >> a >> b;

    // 起点就在终点，无需操作
    if (s == t)
    {
        cout << 0 << endl;
        return 0;
    }

    // dist[i] 记录从起点 s 到达第 i 层的最少按键次数，-1 表示未到达
    vector<int> dist(n + 1, -1);
    queue<int> q;

    dist[s] = 0;
    q.push(s);

    while (!q.empty())
    {
        int u = q.front();
        q.pop();

        if (u == t)
        {
            cout << dist[t] << endl;
            return 0;
        }

        // 尝试按“上”按钮
        if (u + a <= n && dist[u + a] == -1)
        {
            dist[u + a] = dist[u] + 1;
            q.push(u + a);
        }

        // 尝试按“下”按钮
        if (u - b >= 1 && dist[u - b] == -1)
        {
            dist[u - b] = dist[u] + 1;
            q.push(u - b);
        }

        // 尝试按“翻倍”按钮
        if (2 * u <= n && dist[2 * u] == -1)
        {
            dist[2 * u] = dist[u] + 1;
            q.push(2 * u);
        }
    }

    // 搜索结束仍未到达终点，说明无法到达
    cout << -1 << endl;
    return 0;
}
```

#### C++ 语法细节讲解

1. **`std::vector<int> dist(n + 1, -1)`**：
   - 动态数组初始化。由于楼层编号从 $1$ 到 $n$，分配 $n + 1$ 个元素能直接以楼层编号作为下标，避免了“减 1”下标转换；
   - 第二个参数 `-1` 将所有位置默认置为未访问标记。
2. **`std::queue<int>`**：
   - 队列是广度优先搜索的核心容器，具有“先进先出（FIFO）”的特性；
   - `q.push(val)` 将元素压入队尾，`q.front()` 读取队首元素，`q.pop()` 弹出队首。
3. **入队时立即更新距离**：
   - 在 BFS 中，节点被发现时立刻标记 `dist[v] = dist[u] + 1` 并压入队列，可以防止同一个楼层被多次重复加入队列，保证每个楼层仅进出队一次。

### 4.2 Python 参考代码

```python
from collections import deque

def solve():
    n, s, t, a, b = map(int, input().split())

    # 起点就在终点
    if s == t:
        print(0)
        return

    # dist 数组记录从起点 s 到各层的最少步数，-1 表示未到达
    dist = [-1] * (n + 1)
    queue = deque([s])
    dist[s] = 0

    while queue:
        u = queue.popleft()

        if u == t:
            print(dist[t])
            return

        # 尝试按“上”按钮
        if u + a <= n and dist[u + a] == -1:
            dist[u + a] = dist[u] + 1
            queue.append(u + a)

        # 尝试按“下”按钮
        if u - b >= 1 and dist[u - b] == -1:
            dist[u - b] = dist[u] + 1
            queue.append(u - b)

        # 尝试按“翻倍”按钮
        if 2 * u <= n and dist[2 * u] == -1:
            dist[2 * u] = dist[u] + 1
            queue.append(2 * u)

    print(-1)

if __name__ == "__main__":
    solve()
```

#### Python 语法细节讲解

1. **`from collections import deque`**：
   - Python 的标准列表 `list` 在头部弹出 `list.pop(0)` 的时间复杂度为 $O(k)$，会导致整体运行超时；
   - 使用双端队列 `collections.deque` 的 `popleft()` 操作时间复杂度为 $O(1)$，是 Python 编写 BFS 程序的标准规范。
2. **`map(int, input().split())`**：
   - `input().split()` 按空格切分输入行，`map(int, ...)` 将切分后的字符串转换为整数，并一次性解包给变量 `n, s, t, a, b`。
