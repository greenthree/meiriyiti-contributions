# 泡沫啊请不要离去

### 题面描述

“泡沫啊，请不要走，我还不愿与你分别
泡沫啊，请不要走，求求你在这里驻留
如何能让时间停下，让回忆能继续增加
等等我啊，等等我啊，未来啊，请你不要催促

泡沫啊，你听到吗，你是否仍在哪里停留
泡沫啊，你听到吗，有多少话语未说出口
那些寻不回的心情，多想一一说给你听
回忆如同易碎的宝石，闪耀着永恒的光芒

泡沫啊，说再见吧，这是不得已的分别
泡沫啊，说再见吧，相会在下一个世界
喜欢你啊，喜欢你啊，我是如此，爱着你啊
等着我，等着我，微笑着在未来等着我吧

泡沫啊，你听到吗，感谢你，再见了
泡沫啊，你听到吗，相约重逢与此地
那些曾拥有的回忆，就让我珍藏在心底
就像那永不磨灭的宝石，闪耀着永恒的光芒”

这里是查米铃木！宛若奥本海默般沉溺研究的理论系女孩！为了让泡泡更晚离去，她打算研究泡泡的规律！
经过推演，她制作了大小不一的傻笑团子来模拟泡泡的过程：
研究时，她取出其中一个大小的傻笑团子作为某一个时间的大小，接下来按照下面的要求摆放傻笑团子：
1.所有的傻笑团子的大小需要单调递增，前面的团子应该比后面团子小
2.对于每个相邻的傻笑团子，差异不能过大，也就是它们的最大公约数应当大于一
3.如果想让泡泡最晚离去，最后一刻的泡泡应该最小，也就是最后一个傻笑团子尽量小
很可惜，查米铃木相当的丈育！所以请你告诉她，当前的摆放能否完成？如果可以，最后一个傻笑团子最小需要多大？

更形象化的，对于团子长度n，放置的团子idx，团子大小val，有如下要求：
1.全部的n个团子都是正数
2.前一个团子严格小于后一个团子
3.团子[idx] = val（但是团子数组是0索引喔，也就是说，给定的团子是第index+1个！
4.对于任意相邻团子，gcd(团子[i],团子[i+1])>1

### 输入描述

一行三个整数 $n$、$index$、$value$，分别表示团子长度、给定团子的下标（从 $0$ 开始）和该团子的大小。相邻整数之间用一个空格分隔。

### 输出描述

如果无法完成摆放，输出一行 `-1`。

否则输出一行一个整数，表示最后一个傻笑团子的最小大小。

### 样例

**【样例 1】**

**样例输入：**
~~~text
4 2 8
~~~

**样例输出：**
~~~text
10
~~~

#### 样例解释 #1：

可以摆放成 $2,4,8,10$。第 $2$ 个（下标从 $0$ 开始）团子大小是 $8$，相邻团子的最大公约数依次为 $2,4,2$，都大于 $1$。最后一个团子最小为 $10$。

**【样例 2】**

**样例输入：**
~~~text
2 1 3
~~~

**样例输出：**
~~~text
-1
~~~

#### 样例解释 #2：

第二个团子大小固定为 $3$，需要在前一个位置放一个小于 $3$ 且与 $3$ 的最大公约数大于 $1$ 的正整数。小于 $3$ 的正整数只有 $1,2$，它们与 $3$ 都互质，因此无法完成摆放。

**【样例 3】**

**样例输入：**
~~~text
2 0 3
~~~

**样例输出：**
~~~text
6
~~~

#### 样例解释 #3：

第一个团子大小固定为 $3$，第二个团子必须大于 $3$ 且与 $3$ 的最大公约数大于 $1$。最小的合法数是 $6$。

### 提示

- $2 \le n \le 10^9$，$0 \le index \le n-1$，$1 \le value \le 10^9$。
- 可以构造。
- 时间限制 $1$ 秒，空间限制 $256$ MB。
- 所有题目均不强求在最后一行输出后换行。
